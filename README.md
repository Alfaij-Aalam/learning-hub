Learning Hub is a robust, full-stack web application designed to streamline educational 
content delivery and student administration. Built using modern Java technologies, it provides secure 
role-based access for both students and administrators. Students can explore curated tech courses, view detailed
subjects, and manage their personal profiles through a sleek dashboard, while administrators have access to an intuitive 
backend panel to monitor and manage user records.

3. Key Features Bullet Points (For README)
Role-Based Authentication & Authorization: Secure login workflows supporting both hardcoded administrator credentials and MySQL-backed student accounts.

Student Dashboard & Profile Management: Personalized student interface featuring a persistent left-hand sidebar displaying profile details such as email, mobile number, blood group, and age.

Course & Subject Exploration: Dynamic course catalog displaying available technical courses and their respective subject modules.

Admin Control Panel: Dedicated administrative view providing a comprehensive database of registered students with management actions.

Modern Responsive UI: Built using Bootstrap 5, Font Awesome icons, and custom glassmorphism styling for an optimal user experience across devices.

Tech Stack Highlights
Backend: Java, Spring Boot (Web, Data JPA), Hibernate, MySQL 8

Frontend: Thymeleaf, HTML5, CSS3, Bootstrap 5, JavaScript

Version Control: Git & GitHub
